# QWP / HWP 交互式仿真

## 启动与使用

双击本文件夹中的 **启动仿真界面.lnk**。当前电脑所需 Python 环境已经配置在 `.venv` 内。

1. 左侧输入 α（QWP 快轴角）和 β（HWP 快轴角），或拖动对应滑块。
2. 输入停止约 0.22 秒后，右侧五张图同步刷新；也可以按 Enter 立即更新。
3. 右侧上排为原始波形和总频谱，下排为 DC、1f、2f 的局部频谱。
4. 点击 **保存当前结果**，将五张独立 PNG 图片、五张 SVG 矢量图、五图总览及原始数据保存到 `输出结果/时间_角度/`，每次保存使用独立文件夹。
5. **打开结果文件夹** 可查看所有已保存结果；**恢复初始参数** 回到 DC 约 100 mV、Vpp 约 160 mV 的初始状态。
6. 关闭界面会记住有效参数，下次打开继续使用。运行时的错误记录在 `运行日志.log`。

输入框允许 −180°～180°，滑块覆盖常用的 −90°～90°。范围外数值、非数字和 NaN 会提示错误并保留上一次有效结果，禁止保存无效参数。

## 物理含义

光路：P1(−45°) → QWP(α) → HWP(β) → PEM(0°) → P2(+45°) → 探测器。

在 HWP 后、PEM 前定义归一化 Stokes 参数：

```text
s0 = 1
s1 = -sin(2α) cos(4β-2α)
s2 = -sin(2α) sin(4β-2α)
s3 = -cos(2α)
δ(t) = δ0 sin(2π f t)
C = G I0 / 2
V(t) = C [1 + s2 cos δ(t) + s3 sin δ(t)]
```

S1=Ix−Iy、S2=I(+45°)−I(−45°)、S3=2 Im(Ex Ey*)；零度延迟器 Jones 矩阵为 diag(1, exp(iδ))。所有元件角度沿用同一观察方向。

**修改角度时保持 C 不变**，不会重新调节光强/增益，也不会把峰峰值强行缩放回 160 mV。

默认：α=27.775049006°，β=24.715988668°，f=50 kHz，δ0=2.4048255577 rad，C=100 mV。归一化 Stokes 为 [1,−0.6,−0.565685425,−0.565685425]。

- 默认 J0(δ0)≈0，因此 DC≈C=100 mV，**此时改变 α、β，DC 保持不变是正确结果**。
- 1f 随 s3 变化；在这条 QWP→HWP 光路中，β 不改变 s3，因此单独调 β 时 1f 保持不变。
- 2f 随 s2 变化，通常随 α、β 改变。
- 将 δ0 改为其他值，例如 1.8 rad，DC 也会随 s2 改变。
- 左侧 s1 来自波片模型。固定 PEM(0°)+P2(+45°) 对 s1 没有直接灵敏度。

第二张总频谱图的横坐标固定为 **0–250 kHz**，只绘制该范围内的 FFT 频点；界面与导出的独立图片使用同一范围。完整到 Nyquist 的频谱仍保存在 NPZ 文件中。

```text
V_DC = C [1 + J0(δ0) s2]
1f 正弦系数 = 2 C J1(δ0) s3
2f 余弦系数 = 2 C J2(δ0) s2
AC RMS = AC 峰值幅度 / sqrt(2)
```

FFT 的 DC 为均值，不乘 2；其他正频率（Nyquist 除外）乘 2，显示峰值幅度。幅度谱不显示正负号，CSV 另存正弦/余弦系数与相位。零幅度谐波的相位留空。
本模型采用理想完全偏振光、理想波片、平坦探测器频响，不包含斩波器、噪声和电子偏置。

## 文件

- `qwp_hwp_gui.py`：主界面、实时交互和保存逻辑。
- `qwp_hwp_model.py`：固定光强/增益的 Mueller 模型、FFT 和结果导出。
- `simulation_core.py`：沿用上一版的 Mueller/Jones 矩阵和独立图片绘制函数。
- `test_simulation.py`：模型测试，包含已知偏振态、固定增益、Jones 对照、FFT 与贝塞尔校验。
- `输出结果/默认参数`：已生成的初始五图与数据。
- `输出结果/时间_角度`：在界面点击保存后生成的结果。

## 在其他 Python 环境运行

```powershell
python -m pip install -r requirements.txt
python qwp_hwp_gui.py

# 忽略上次参数，恢复默认启动：
python qwp_hwp_gui.py --default

# 无需打开界面，导出初始五图：
python qwp_hwp_gui.py --export-default

# 运行物理和数值测试：
python test_simulation.py
```

需要 Python 3.10+ 和 tkinter（标准 Windows Python 一般自带）。快捷方式使用当前文件夹的绝对路径；移动整个文件夹或换电脑后，请按上述命令启动并重新创建快捷方式。
